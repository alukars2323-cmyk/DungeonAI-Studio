# Сайт без отдельного сервера

Версия для GitHub Pages работает целиком в браузере: собственные PNG и ZIP, текстуры полов и стен, процедурная генерация, редактор, проекты и экспорт PNG. Проекты и изображения хранятся в IndexedDB на устройстве пользователя, а не в GitHub. ИИ доступен только в серверной версии; ключи в статический сайт не добавляются.

## Первый запуск подготовленного сайта

После загрузки готовой сборки в ветку `gh-pages`:

1. Откройте [настройки Pages](https://github.com/alukars2323-cmyk/DungeonAI-Studio/settings/pages).
2. В разделе **Build and deployment** выберите **Source → Deploy from a branch**.
3. Выберите ветку **gh-pages**, папку **/ (root)** и нажмите **Save**.
4. Дождитесь окончания публикации: GitHub покажет адрес сайта и кнопку **Visit site**.

Стандартный адрес проекта — `https://alukars2323-cmyk.github.io/DungeonAI-Studio/`. Этот адрес становится рабочим только после успешного включения Pages и публикации. Наличие ветки с файлами не подтверждает работу внешнего сайта.

Если GitHub не позволяет включить Pages для этого репозитория, доступность зависит от его видимости и тарифа GitHub. Эта настройка не меняется автоматически приложением.

## Сборка и проверка

```bash
npm ci
npm run build:pages
npm run test:pages
```

Сборка находится в `dist-pages`, использует базовый путь `/DungeonAI-Studio/` и не содержит source maps. Проверочный сервер `npm run preview:pages` отдаёт только файлы сайта; обращений к серверному `/api` не требуется.

Для автоматических будущих публикаций в репозитории подготовлен workflow `.github/workflows/pages.yml`: после включения **Source → GitHub Actions** и размещения исходников в `main` он собирает сайт и публикует его при изменениях. Начальная готовая ветка `gh-pages` позволяет открыть сайт без этого переключения.

## Данные и прежние проекты

Сохранение действует в этом браузере на этом устройстве. Для копии скачайте JSON проекта и сохраните исходные PNG: JSON содержит ссылки на библиотеку, а не изображения. Очистка данных сайта удаляет IndexedDB.

Исходный HTML-прототип 0.1 сохранён без изменений в `public/legacy/index.html`. На опубликованном сайте он доступен через справку **Открыть исходную версию (v0.1)**. Его старый JSON, темы и загрузка WebP остаются в отдельной исходной версии; новый формат `.dungeonai.json` не выдаётся за формат этого прототипа.
