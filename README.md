# DungeonAI Studio

Локальное веб-приложение для создания и редактирования тактических карт. Русский интерфейс, библиотека собственных PNG, генерация по описанию, редактируемые проекты и экспорт изображений.

Есть версия **для GitHub Pages без отдельного сервера**: `npm run build:pages`. Она хранит проекты и PNG в браузере, поддерживает процедурную генерацию и не требует ключей. [Как включить подготовленный сайт](docs/github-pages.md). Серверный вариант с опциональным ИИ сохранён.

## Запуск

Проверенная среда: Node.js 24.19.0, npm 11.9.0, Linux и Chromium. Node.js должен быть версии 22 или новее; для работы с прокси из облачной среды рекомендуется Node.js 24.

```bash
cd /workspace/DungeonAI-Studio
npm ci --cache /tmp/dungeonai-npm-cache
npm run dev
```

API и интерфейс запускаются одним процессом на порту `3001`, по умолчанию на `127.0.0.1`. `HOST` и `PORT` можно задать переменными окружения. Для собранной версии:

```bash
npm run build
npm start
```

Не создавайте дополнительный Git worktree для облачных задач: используйте существующий изолированный checkout.

## Что работает

- Импорт PNG и ZIP с PNG, включая вложенные папки. Изображения проверяются декодированием и CRC; повреждённые файлы и небезопасные архивы отклоняются.
- Библиотека с поиском, категориями и тегами. PNG категории «Объекты» размещаются на карте; «Полы» и «Стены» используются как повторяемые текстуры.
- Локальный генератор учитывает русские/английские описания количества комнат, тему, ключевые слова и seed. Комнаты соединяются коридорами; стены формируются по общему периметру. Запрошенное количество ограничивается размером карты и максимумом 24 комнаты.
- Отдельный режим ИИ через серверный OpenAI API с проверкой структуры, границ, связности и ссылок на ассеты. Без настроенного ключа кнопка ИИ недоступна; процедурный режим работает самостоятельно.
- Ручные помещения, коридоры и стены, размещение PNG и восьми встроенных объектов, перемещение, размеры, подписи, материалы, поворот, дублирование, удаление, undo/redo, сетка, привязка, масштаб и панорамирование.
- Сохранение и открытие проектов на сервере; восстановление последнего черновика в браузере. JSON проекта можно скачать и импортировать как новый проект.
- Экспорт PNG в разрешении 1×, 2× или 3×, с сеткой или без. Экспорт включает все слои независимо от их видимости в редакторе и не включает выделение.

## Форматы Dungeondraft

**Нативные `.dungeondraft_pack` и `.dungeondraft_map` сейчас не поддерживаются.** ZIP с PNG является импортом изображений, а не парсером нативного пакета. Бинарный пакет явно отклоняется. Извлеките изображения доступным вам инструментом и загрузите PNG напрямую или в ZIP.

Редактируемый формат этой версии — `.dungeonai.json` (`schemaVersion: 1`), не формат Dungeondraft. Он содержит ссылки на изображения из библиотеки сервера, а не сами PNG. Для переноса на другой сервер сохраняйте каталог данных целиком. Нативный экспорт запланирован через отдельный адаптер после проверки на настоящих файлах и открытия результата в Dungeondraft.

## Хранение

По умолчанию данные лежат в `.data/assets` и `.data/projects`; они исключены из Git. Каталог задаётся `DUNGEON_DATA_DIR`. Для резервной копии остановите процесс и скопируйте весь каталог. Изображение, используемое сохранённым проектом, нельзя удалить. JSON с отсутствующими ассетами не сохраняется.

Лимиты: 8 МиБ на файл, 16 МиБ суммарной загрузки, до 32 загружаемых файлов, до 200 записей архива и 64 МиБ после распаковки. PNG — до 8192 пикселей по стороне и 16 мегапикселей. Карта — от 12×12 до 80×80 клеток, 32 пикселя на клетку до масштабирования экспорта.

Приложение рассчитано на личную локальную мастерскую. Пользовательские аккаунты и совместное редактирование в эту версию не входят.

## ИИ

Задайте `DUNGEON_AI_KEY` через защищённые настройки среды сервера. Не присылайте ключ в чат и не добавляйте его в Git. Необязательная переменная `DUNGEON_AI_MODEL` имеет значение по умолчанию `gpt-4.1-mini`. Перезапустите сервер после изменения переменных.

Шаблон имён находится в `.env.example`; сервер читает переменные процесса, **автоматической загрузки `.env` нет**. Требуется HTTPS-доступ к `api.openai.com`. Скрипты запуска включают поддержку системного HTTP/HTTPS-прокси в Node.js 24 и сохраняют проверку TLS.

ИИ получает описание карты и метаданные выбранных ассетов (названия, теги и размеры); изображения не отправляются. Ответ провайдера проверяется перед созданием документа. Ошибка ИИ не подменяется локальным результатом. Реальный вызов провайдера требует доступного ключа; тесты адаптера используют контролируемые ответы.

## Проверки

```bash
npm test
npm run build
npm run test:e2e
npm run build:pages
npm run test:pages
```

Для браузерных тестов используется системный `/usr/bin/chromium`; другой путь задаётся `CHROMIUM_PATH`. Тесты запускают отдельный сервер на порту 3101 и отдельное хранилище в `/tmp`, не затрагивая рабочие проекты.

Обязательные проверки среды: установка по lockfile, тесты генератора/API, проверка типов и сборка, запуск сервера и функциональные сценарии в браузере. Реальный вызов ИИ и совместимость нативных файлов Dungeondraft проверяются отдельно, когда доступны необходимые ключи и образцы.

Описание модулей, контрактов и дальнейшей интеграции: [docs/architecture.md](docs/architecture.md).

Исходный HTML-прототип 0.1 сохранён в `public/legacy/index.html`; ссылка на него находится в справке приложения. Старые JSON-проекты и прежние инструменты доступны там.
